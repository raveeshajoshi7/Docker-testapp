# Dockerized Node.js Application with MongoDB

## Overview

This project was built as part of my Docker learning journey to understand containerization and multi-container application deployment.

The application consists of:

- Node.js application
- MongoDB database
- Mongo Express web interface
- Docker containers for application deployment

## Architecture

Node.js Application
        |
        v
     MongoDB
        |
        v
   Mongo Express

## Technologies Used

- Docker
- Node.js
- MongoDB
- Mongo Express
- JavaScript

## Learning Objectives

- Create Docker images using Dockerfile
- Run and manage containers
- Connect multiple containers
- Configure MongoDB in containers
- Access database through Mongo Express
- Understand container networking
- Work with environment variables

## Key Concepts Practiced

- Docker build
- Docker run
- Container networking
- Port mapping
- Database connectivity
- Multi-container environments
